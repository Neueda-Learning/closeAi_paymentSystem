## 前端架构梳理
- 通读 payment-system-frontend 全部 16 个源文件，输出分层架构图(Visualizer SVG)。
- 技术栈: Vue 3 (script setup) + Vite 5 + Element Plus + Pinia + Vue Router 4 + ECharts 6 (vue-echarts) + Axios。
- 分层: index.html → main.js(挂载+插件) → App.vue/router(shell) → views(4 页) → components(6 个可复用) → service(api/index.js axios 实例 + api/payment.js 15 个接口 + utils/constants.js 状态/错误映射) → 后端 Spring Boot :8080(vite proxy /api)。
- 业务核心: 支付状态机 CREATED→VALIDATED→SENT→COMPLETED(及 FAILED/CANCELLED/REVERSED), 重试上限 3 次, 幂等键 Idempotency-Key。
- 约定: 统一后端响应体 {success, data, error}, axios 拦截器解包+ElMessage 报错; constants.js 集中管理状态颜色/动作/错误码。
