# Payment Processing System — 启动指南

## 环境要求

| 组件 | 版本要求 | 验证命令 |
|------|---------|----------|
| JDK | 17+ | `java -version` |
| Maven | 3.8+ | `mvn -version` |
| MySQL | 8.0+ | `mysql --version` |
| Node.js | 18+ | `node -v` |
| npm | 9+ | `npm -v` |

## 第一步：启动 MySQL

### 1.1 启动 MySQL 服务

```bash
# 启动 MySQL 守护进程（自定义数据目录）
"/c/Program Files/MySQL/MySQL Server 8.4/bin/mysqld" \
  --datadir="$HOME/mysql-data" \
  --port=3306 \
  --console &

# 等待 MySQL 就绪
sleep 3
```

### 1.2 创建数据库（首次运行）

```bash
# 创建数据库
"/c/Program Files/MySQL/MySQL Server 8.4/bin/mysql" \
  -u root -h 127.0.0.1 -P 3306 \
  -e "CREATE DATABASE IF NOT EXISTS payment_system CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 导入建表脚本（含索引）
"/c/Program Files/MySQL/MySQL Server 8.4/bin/mysql" \
  -u root -h 127.0.0.1 -P 3306 payment_system \
  < backend/src/main/resources/db/schema.sql

# 验证表创建成功
"/c/Program Files/MySQL/MySQL Server 8.4/bin/mysql" \
  -u root -h 127.0.0.1 -P 3306 payment_system \
  -e "SHOW TABLES;"
```

> **注意：** MySQL 连接配置为 `root / 空密码 / payment_system`。如果环境不同，修改 `backend/src/main/resources/application.yml` 中的 `${DB_URL}`、`${DB_USERNAME}`、`${DB_PASSWORD}` 环境变量。

### 1.3 检查 MySQL 状态

```bash
"/c/Program Files/MySQL/MySQL Server 8.4/bin/mysql" \
  -u root -h 127.0.0.1 -P 3306 -e "SELECT 1 AS alive;"
```

看到 `alive: 1` 表示 MySQL 运行正常。

## 第二步：启动后端

```bash
cd backend
mvn spring-boot:run
```

### 验证后端启动

```bash
curl -s http://localhost:8080/v3/api-docs | head -c 100
```

看到 JSON 返回（含 `"openapi":"3.0.1"`）表示启动成功。

### 可选：访问 Swagger UI

浏览器打开 `http://localhost:8080/swagger-ui.html`，可在页面上直接测试所有 API。

### 快速冒烟测试

```bash
curl -s -X POST http://localhost:8080/api/payments \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: smoke-test-001" \
  -d '{"sourceAccount":"ACC-001","destinationAccount":"ACC-002","amount":500.00,"currency":"USD","description":"Smoke test"}'
```

返回 HTTP 201 + 支付 ID 表示启动成功。

## 完整启动流程（一键脚本）

将以下内容保存为 `start-all.sh`：

```bash
#!/bin/bash
echo "=== Starting Payment System ==="

# 1. MySQL
echo "[1/3] Starting MySQL..."
"/c/Program Files/MySQL/MySQL Server 8.4/bin/mysqld" \
  --datadir="$HOME/mysql-data" --port=3306 --console > /tmp/mysql.log 2>&1 &
sleep 3
mysql -u root -h 127.0.0.1 -P 3306 -e "SELECT 1;" 2>/dev/null && echo "  MySQL: OK" || echo "  MySQL: FAILED"

# 2. Backend
echo "[2/3] Starting Backend..."
cd backend
mvn spring-boot:run > /tmp/backend.log 2>&1 &
BACKEND_PID=$!
cd ..
sleep 20
curl -s http://localhost:8080/v3/api-docs > /dev/null 2>&1 && echo "  Backend: OK (PID=$BACKEND_PID)" || echo "  Backend: STARTING..."

# 3. Frontend
echo "[3/3] Starting Frontend..."
cd frontend
npm run dev > /tmp/frontend.log 2>&1 &
FRONTEND_PID=$!
cd ..
sleep 4
curl -s http://localhost:5173 > /dev/null 2>&1 && echo "  Frontend: OK (PID=$FRONTEND_PID)" || echo "  Frontend: STARTING..."

echo ""
echo "=== All services started ==="
echo "  Frontend:  http://localhost:5173"
echo "  Backend:   http://localhost:8080"
echo "  Swagger:   http://localhost:8080/swagger-ui.html"
echo "  MySQL:     localhost:3306 / payment_system"
```

## 服务总览

| 服务 | 地址 | 用途 |
|------|------|------|
| **前端页面** | `http://localhost:5173` | 用户操作界面 |
| **后端 API** | `http://localhost:8080/api/payments` | REST 服务 |
| **Swagger UI** | `http://localhost:8080/swagger-ui.html` | API 在线文档与调试 |
| **MySQL** | `localhost:3306` | 数据持久化 |

### 数据库连接

| 参数 | 值 |
|------|-----|
| Host | `127.0.0.1` |
| Port | `3306` |
| User | `root` |
| Password | (空) |
| Database | `payment_system` |

### Vite 代理配置

前端所有 `/api/*` 请求自动转发到后端 `http://localhost:8080`，无需手动配置 CORS。

## 常见问题

### MySQL 启动失败

```bash
# 如果已有的数据目录损坏，重新初始化
rm -rf "$HOME/mysql-data"
mkdir -p "$HOME/mysql-data"
"/c/Program Files/MySQL/MySQL Server 8.4/bin/mysqld" --initialize-insecure --datadir="$HOME/mysql-data"
```

### 端口被占用

```bash
# 查看端口占用
netstat -ano | grep ":8080"
netstat -ano | grep ":5173"
netstat -ano | grep ":3306"

# 强制释放（Windows）
taskkill //F //PID <PID>
```

### 后端无法连接 MySQL

检查 `application.yml`：
```yaml
spring:
  datasource:
    url: ${DB_URL:jdbc:mysql://localhost:3306/payment_system?...}
    username: ${DB_USERNAME:root}
    password: ${DB_PASSWORD:}
```

可通过环境变量覆盖默认值：
```bash
export DB_URL=jdbc:mysql://other-host:3306/payment_system?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC
export DB_USERNAME=myuser
export DB_PASSWORD=mypass
```

### 前端依赖安装慢

```bash
# 使用淘宝镜像
npm install --registry=https://registry.npmmirror.com
```

### 数据库需要重建

```bash
"/c/Program Files/MySQL/MySQL Server 8.4/bin/mysql" -u root -h 127.0.0.1 -P 3306 -e "DROP DATABASE payment_system; CREATE DATABASE payment_system CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
"/c/Program Files/MySQL/MySQL Server 8.4/bin/mysql" -u root -h 127.0.0.1 -P 3306 payment_system < backend/src/main/resources/db/schema.sql
```
