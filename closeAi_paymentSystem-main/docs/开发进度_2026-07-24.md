### 9 个 REST API 端点
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/payments | 创建支付 (201 新 / 200 幂等重复) |
| GET | /api/payments | 列表查询（status/currency/keyword/page/limit） |
| GET | /api/payments/{id} | 支付详情 + 状态历史 |
| GET | /api/payments/{id}/history | 状态历史（瘦身数组） |
| POST | /api/payments/{id}/validate | 验证 (CREATED→VALIDATED) |
| POST | /api/payments/{id}/send | 发送 (VALIDATED→SENT, 20%模拟失败) |
| POST | /api/payments/{id}/complete | 完成 (SENT→COMPLETED) |
| POST | /api/payments/{id}/fail | 标记失败 |
| POST | /api/payments/{id}/retry | 重试 (FAILED→VALIDATED) |

### 数据库表
- `payments` — 含 version 乐观锁字段 + 3 个索引
- `status_history` — 全量审计日志
- `idempotency_keys` — 幂等去重

## 对话要点回顾

1. **技术栈选定**: Spring Boot + MySQL + MyBatis-Plus + Vue 3（Monorepo）
2. **开发顺序**: 后端 → 测试 → 前端 → AI 异常检测
3. **AI 异常检测**: 暂不做，前后端打通后再扩展
4. **幂等性**: 采用 Idempotency-Key header + 数据库唯一约束 + 写前 SELECT 快路径
5. **乐观锁**: version 字段 + MyBatis-Plus OptimisticLockerInnerInterceptor
6. **验证分层**: validateOnCreate（轻量快速失败） + validateOnTransition（完整业务校验，失败转 FAILED）
7. **设计系统**: Revolut 风格 DESIGN.md
